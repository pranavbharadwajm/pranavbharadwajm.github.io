Accredian EdTech Dashboard

Skills Applied: Product Management • User Experience • Data Structuring
The Prompt: "Design a student dashboard feature that increases daily active user engagement while consolidating complex course data into a single, digestible view."

When approaching the dashboard architecture, the primary bottleneck was information overload. Students were abandoning the platform because finding specific modules required too many clicks.

The Approach

I applied a systems-thinking framework to map the exact user journey. By restructuring the data hierarchy, I prioritized immediate actionable items like upcoming deadlines at the top level.

The Outcome

The revised structural plan significantly reduced navigational friction, providing a clear blueprint for the engineering team to execute the build.
